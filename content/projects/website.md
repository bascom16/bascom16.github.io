This website is built with [Next.js](https://nextjs.org) (App Router), TypeScript, and [Tailwind CSS](https://tailwindcss.com), and deployed as a static site to GitHub Pages via GitHub Actions.

Content is written in Markdown with YAML frontmatter and parsed at build time using [gray-matter](https://github.com/jonschlinkert/gray-matter) and [remark](https://github.com/remarkjs/remark).
