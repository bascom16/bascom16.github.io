# bascom16.github.io

Personal portfolio and academic website for Brian Bascom, built with [Claude Code](https://claude.ai/code).

## Tech Stack

- [Next.js](https://nextjs.org) (App Router, static export)
- TypeScript + Tailwind CSS v4
- Markdown content with gray-matter + remark
- Deployed to GitHub Pages via GitHub Actions

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
